# 销售助手 · Sales Copilot 详情

中英双语销售助手，装在 DSH 里，不改变你原有的使用习惯：侧边栏底部多一个「销售助手」按钮，
点开是右侧浮动面板，六个页签。面板左边缘可以拖动改宽度（360–1200px，双击左边缘恢复默认），
宽度会记在本机，下次打开还是这个宽。

## 六个页签

### 1. 快查
输入客户说的话（中文或英文都行），220 毫秒防抖后返回最匹配的 3 条问答，带命中率徽标。
每条分两栏：**中文要点**（理解用）和**照着念**（英文，≤25 词）。适合开会前临时抱佛脚。

### 2. 实时
呼叫系统已装的 `dsh-live-captions` 当耳朵：由它负责采集系统声音/麦克风、语音识别、翻译，
本插件只做一件事——把识别出来的句子立刻拿去检索问答库，命中就给出「中文要点 + 英文照读」，
并按命中率排序、最多保留 40 张卡片。

- 第一次点「开始听」会自动把 `dsh-live-captions` 拉起来；没装它时会直接提示。
- 打开「AI 精确回答」后，同一句话会额外问一次当前 DSH 默认模型，输出
  `{"zh": "≤30 字要点", "en": "≤25 词照读英文"}`，写在卡片最下方。
- 关掉 AI 回答时零模型调用、零 token 消耗，只有本地检索。
- 点「置顶浮层」会在屏幕右下角打开一个置顶小窗（470px 宽），通话软件挡住 DSH 时也能看答案；
  窗内显示原话 / 中文要点 / 英文照读 / 命中率，「锁定」后鼠标穿透、不挡操作，拖标题栏可移动。
- 通话结束（字幕自己停或你点「停止」）后，顶部会出现「这段通话结束了 · 共 N 句，要生成纪要吗？」，
  点「生成纪要并写画像」= 导入这场通话字幕 → 总结 → 写回客户档案；点「先不要」收起。

前置条件：`dsh-live-captions` 的翻译建议指向本地免费翻译桥（`http://127.0.0.1:8787/v1`，
模型 `free-google-microsoft`），否则每句话要走云端，延迟会上去。

### 3. 对练
会议室式对练，四段：

1. **角色**：内置 3 个客户角色（德国汽配采购总监 / 东南亚电商运营 / 宁波五金厂长），
   可以改提示词、可以删、也可以输入一段背景让模型一次生成 3 个角色。
2. **对练**：新建一场对练，选「AI 扮客户」或「我扮客户」，关联客户档案。
3. **从通话记录生成纪要**：读取 `dsh-live-captions` 存下的通话字幕，选一段导入，
   自动整理成一场 `call-import` 对练并总结需求、写回客户画像。
4. **会话**：顶部「← 返回列表」「朗读客户台词」「自动朗读：开/关」「客户接着说」、
   「语音回答」「总结并写入画像」；消息按销售/客户左右分栏，底部可切换「我演销售 / 我演客户」手打发话。

**语音**：客户台词可用 Windows 自带 SAPI 念出来（`native/speak.ps1`，零下载，按语言自动挑选
中文 `Microsoft Huihui Desktop` / 英文 `Microsoft Zira Desktop`）；「语音回答」会临时把
`dsh-live-captions` 切到麦克风，你说一句、它识别成文字当作你的发言，随后自动停并还原设置。

总结会输出四块：结论、客户需求、下一步、画像（阶段/预算/备注/标签），
勾选「写入画像」会把它们合并回该客户档案。

### 4. 问答库
新增 / 编辑 / 删除 / 筛选 / 批量导入 / 补示例。导入支持三种格式：

```
标准版多少钱？	标准版年费 ¥68,000。
Q: 上线要多久？
A: 标准版 2 周、专业版 4–6 周。
能对接 ERP 吗？ | 标准 API 加预置连接器。
```

### 5. 客户
客户档案：名称、公司、阶段、预算、标签、备注。对练与总结都挂在这里。

### 6. 设置
显示真实数据目录、最常被问的 8 条、一键导出整个库（JSON）。
