# 销售助手 · Sales Copilot 详情

中英双语销售助手，装在 DSH 里，不改变你原有的使用习惯：侧边栏底部多一个「销售助手」按钮，
点开是右侧浮动面板，六个页签。面板左边缘可以拖动改宽度（360–1200px，双击左边缘恢复默认），
宽度会记在本机，下次打开还是这个宽。

## 六个页签

### 1. 快查
输入客户说的话（中文或英文都行），220 毫秒防抖后返回最匹配的 3 条问答，带命中率徽标。
每条分两栏：**中文要点**（理解用）和**照着念**（英文，≤25 词）。适合开会前临时抱佛脚。

### 2. 实时
呼叫系统已装的 `dsh-live-captions` 当耳朵：由它负责采集系统声音/麦克风、语音识别、翻译，
本插件只做一件事——把识别出来的句子立刻拿去检索问答库，命中就给出「中文要点 + 英文照读」，
并按命中率排序、最多保留 40 张卡片。

- 第一次点「开始听」会自动把 `dsh-live-captions` 拉起来；没装它时会直接提示。
- 打开「AI 精确回答」后，同一句话会额外问一次当前 DSH 默认模型，输出
  `{"zh": "≤30 字要点", "en": "≤25 词照读英文"}`，写在卡片最下方。
- 关掉 AI 回答时零模型调用、零 token 消耗，只有本地检索。
- 点「置顶浮层」会在屏幕右下角打开一个置顶小窗（470px 宽），通话软件挡住 DSH 时也能看答案；
  窗内显示原话 / 中文要点 / 英文照读 / 命中率，「锁定」后鼠标穿透、不挡操作，拖标题栏可移动。
  关闭方式有三种：**按 Ctrl+Alt+Q**（锁定穿透时也能用）、回面板点「收起浮层」、或点窗内右上角的 ×（未锁定时）。
- 通话结束（字幕自己停或你点「停止」）后，顶部会出现「这段通话结束了 · 共 N 句，要生成纪要吗？」，
  点「生成纪要并写画像」= 导入这场通话字幕 → 总结 → 写回客户档案；点「先不要」收起。

前置条件：`dsh-live-captions` 的翻译建议指向本地免费翻译桥（`http://127.0.0.1:8787/v1`，
模型 `free-google-microsoft`），否则每句话要走云端，延迟会上去。

### 3. 对练
会议室式对练，四段：

1. **角色**：内置 3 个客户角色（德国汽配采购总监 / 东南亚电商运营 / 宁波五金厂长），
   可以改提示词、可以删、也可以输入一段背景让模型一次生成 3 个角色。
2. **对练**：新建一场对练，两种模式都是**真实可用**的：
   - **AI 扮客户 · 你练销售**：AI 按角色扮演买家（会压价、问上线周期、拿竞品比较），你练销售话术。
   - **你扮客户 · AI 练销售**：你扮演客户开口，AI 扮演销售顾问，基于产品资料回应你的异议、追问需求、推进下一步。
   关联客户档案后，对练总结会写回画像。
3. **从通话记录生成纪要**：读取 `dsh-live-captions` 存下的通话字幕，选一段导入，
   自动整理成一场 `call-import` 对练并总结需求、写回客户画像。
4. **会话**：顶部「← 返回列表」「朗读 AI 台词」「自动朗读：开/关」「客户/销售接着说」、
   「总结并写入画像」「删除这场对练」；消息按销售/客户左右分栏，底部可切换「我演销售 / 我演客户」手打发话。
   「④ 历史对练」列出所有场次，每行的「打开」回到那场对话、「删除」连同消息和总结一起删除；
   删的正好是当前语音对练的那场时，服务端会同时停掉麦克风采集。

**语音（两种方式）**：

- **朗读引擎**（按优先级自动降级）：① **小米 MiMo TTS**（默认，自然神经音色，中文「冰糖」、英文「Mia」）；② edge-tts（微软 Edge 免费神经语音）；③ Windows SAPI（离线兜底）。小米密钥放在 `~/.dsh/sales-copilot/tts-config.json`（不进代码库），也支持环境变量 `MIMO_API_KEY`。朗读按回复实际语言选音色，中英文都自然、不乱码，多句会排队念完不互相打断。
- **语音实时对练**（推荐）：在会话顶部点「开始语音对练」。它独占麦克风（通过 `dsh-live-captions`，
  会临时把采集源切到麦克风、关闭机器翻译并锁定识别语言，结束后自动还原），你连续说，AI 自动回应并用神经语音朗读出来。
  两种模式都支持：AI 扮客户时你说销售的话；你扮客户时 AI 演销售。界面每秒刷新，显示「你刚说 / AI 回应 / 轮次」。
  可在卡片里选「识别语言」（自动按模式 / 中文 / English）；短句用固定语言识别比自动判断准。
  开始语音对练前先停止「实时」辅助（两者争用麦克风）。
- **说一句**（单次）：点「说一句」，说一句话识别后作为你这一侧的发言，不自动回复，适合临时补一句。

> 识别用的本地免费翻译桥在部分网络下会失败（`google: aborted / microsoft: bad JSON`），
> 那会把字幕改坏、拖慢速度。因此语音对练只读原始识别文本、不经过翻译。

总结会输出四块：结论、客户需求、下一步、画像（阶段/预算/备注/标签），
勾选「写入画像」会把它们合并回该客户档案。

### 4. 问答库
新增 / 编辑 / 删除 / 筛选 / 批量导入 / 补示例。导入支持三种格式：

```
标准版多少钱？	标准版年费 ¥68,000。
Q: 上线要多久？
A: 标准版 2 周、专业版 4–6 周。
能对接 ERP 吗？ | 标准 API 加预置连接器。
```

### 5. 客户
客户档案：名称、公司、阶段、预算、标签、备注。对练与总结都挂在这里。

### 6. 设置
显示真实数据目录、最常被问的 8 条、一键导出整个库（JSON）。
